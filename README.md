# YOL — Yet Optical Linker

YOL (Yet Optical Linker) is a lightweight TCP port scanning and banner grabbing tool written in C++.

Built as a hands-on project to explore Linux socket programming, TCP connections, and network service identification, YOL aims to develop into a modular and practical networking utility.

### Current Features
- Interactive terminal interface
- IPv4 address input
- Custom TCP port range selection
- TCP connect scanning
- Basic service banner grabbing
- Socket-based networking using Linux system libraries

### Development
YOL is currently in its early development stage (v0.1). Features, reliability, and code organization will improve gradually as development continues.

### Technology
- C++
- Linux Socket API
- TCP/IP
- Git
